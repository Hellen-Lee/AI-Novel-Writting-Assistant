## 4. 布局规则

1. 卡片宽度自适应，禁止固定 px 宽。
2. 同行最多 2 张同类型卡；≤960px 单列；`story_core` / `outline` / 世界观主卡保持单列堆叠。
3. 非世界观卡：默认高 + 最大高，正文区滚动（人物 328；内核/大纲默认 160、上限 328）。世界观不限高。
