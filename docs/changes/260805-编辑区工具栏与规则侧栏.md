> 设计稿：`docs/Novel.pen` → `Editor-Toolbar`（`d7ubn`）/ `Editor-Rules`（`RvfPH`）/ `Agent-History`（`OckRz`）  
> 代码：`frontend/src/pages/EditorPage.*`、`components/editor/EditorToolbar.*`、`EditorRightRail.*`、`components/editor/Agent/`  
> 说明：本文为迭代过程记录；架构笔记见 `docs/build/03-编辑页.md`。旧 IA（规则作为 Agent 头栏遮罩）已弃用。

---

## 1. 目标

- 编辑区右上角增加工具栏：**Agent 对话 / 规则 / 导出（占位）**。
- 将「创作规则」从 Agent 对话内独立为右侧整栏，由工具栏切换。
- 历史会话仅对齐 `OckRz` 界面壳，搜索/重命名/删除/清空等逻辑不做。

---

## 2. IA 变更

| 之前 | 之后 |
| --- | --- |
| `useAgentPanel.panelMode`: `chat \| history \| rules` | 页面级 `rightPanel: { open, mode: 'agent' \| 'rules' }`；Agent 内仅 `chat \| history` |
| Agent 头栏：历史 / 新建 / 临时规则（FilePen） | Agent 头栏：历史 / 新建 / 收起（PanelRightClose） |
| 规则 = Agent 内全屏遮罩，「← AI 对话」返回 | 规则 = 独立 `RulesPanel` 侧栏，标题「创作规则」+ 关闭 |
| 无编辑区工具栏 | `EditorToolbar` 绝对定位于正文区右上角 |

---

## 3. 组件职责

```
EditorPage
├─ rightPanel / useAgentRules（tempRules 上提）
├─ ChapterSidebar
├─ ChapterMain + EditorToolbar
└─ EditorRightRail
    ├─ mode=agent → AgentPanel（会话保持挂载，切规则时 hidden）
    └─ mode=rules → RulesPanel
```

| 组件 | 职责 |
| --- | --- |
| `EditorToolbar` | 三图标按钮；active / 临时规则小圆点；导出触发页内 notice |
| `EditorRightRail` | 按 mode 展示 Agent 或规则；`open=false` 整栏隐藏 |
| `RulesPanel` | 全局规则 / 文风偏好只读 + 临时规则编辑；保存写回 `tempRules` |
| `HistoryPanel` | 搜索禁用、今天/昨天/更早分组占位、底栏计数与清空禁用 |
| `useAgentRules` | 仍在 Agent/hook，由 `EditorPage` 调用（`active` 控制拉取只读设置） |
