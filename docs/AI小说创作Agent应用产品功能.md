# AI小说创作Agent应用产品初步计划书

---

请基于以下完整需求，生成一份**AI 小说创作 Agent 应用产品初步计划书**，要求内容专业、结构清晰、具备产品落地参考性，覆盖产品定位、功能全景、核心流程、技术架构、迭代规划等核心维度。

### 一、产品核心定位

面向网文作者、原创小说创作者、写作爱好者的智能创作辅助工具，基于 Agent 智能体架构，覆盖从世界观搭建到正文续写的小说创作全流程；核心特点是具备长期创作记忆、可自定义创作规则、支持灵活接入外部大模型 API，保障 AI 生成内容的设定一致性与风格统一性，辅助创作者高效产出。

### 二、Agent 核心底层能力（核心需求）

1. **外部模型可插拔接入**

    - 支持用户自主配置接入主流大模型 API（含 GPT 系列、Claude、通义千问、DeepSeek、文心一言等），支持手动填写 API 密钥、选择调用模型

    - 支持自定义模型生成参数（温度、top\_p、最大上下文长度、回复截断规则等），可针对不同创作场景配置不同模型参数

    - 支持不同创作环节（设定生成、正文续写、润色优化）调用不同模型，灵活分配算力

2. **自定义创作规则系统**

    - 支持全局规则配置：包括文风要求、叙事视角、禁忌内容、世界观底层逻辑、人物行为准则、剧情合规要求等

    - 支持场景化临时规则：可针对单章节、单场景添加专属创作规则，可设定规则优先级

    - 规则支持保存为模板、多项目复用，Agent 所有生成行为必须严格遵循已配置的规则约束

3. **分层记忆与进化系统**

    - 长期记忆库：自动提取并存储小说全量设定（世界观、人物、物品、剧情伏笔）；人物关系内嵌于人物设定（`relationship`），跨章节保持内容一致性，避免设定冲突

    - 短期上下文记忆：保留最近 3 章正文内容、当前场景细节，保障续写的上下文连贯

    - 记忆进化机制：随着创作字数 / 章节数累积，自动从新内容中提取新增设定、更新人物（含关系）与剧情线，主动向用户同步记忆更新，支持人工修正记忆内容

    - 记忆可检索、可编辑、可导出，支持手动修正 AI 提取的错误记忆

4. **创作技能库**

    - 内置多类写作技能：开篇撰写、人物出场描写、战斗 / 情绪 / 环境场景渲染、剧情反转设计、大纲扩写、伏笔回收、内容润色、对话优化等

    - 支持用户自定义技能：可自行编写技能提示词、设定技能触发方式，保存为专属技能一键调用

    - 技能可组合调用，支持链式完成复杂创作任务

### 三、产品端功能模块（对应图示完整落地）

1. **介绍页**：产品核心价值展示、功能亮点介绍、创作效果案例演示、新用户入口引导，突出 Agent 记忆连续、设定不崩的核心优势

2. **登录注册页**：支持手机号、邮箱、第三方账号登录，支持游客模式体验，账号云端同步所有创作项目、设定与记忆数据

3. **引导页（单页创建项目）**

    - 一页汇总：题材 & 世界观、故事内核、主要角色、全本大纲

    - 支持 **AI 一键生成全部**（题材/内核/人物/大纲协同）；也可分区块 AI 生成或手动填写

    - 部分卡片可点击展开，在模态窗中详细编辑后回写

    - 确认后初始化创作项目与设定/记忆库，进入编辑器

4. **仪表盘**：创作项目总览面板，展示在写作品、总字数、创作进度、最近编辑记录，推送记忆进化提醒、创作建议，提供快捷创作入口

5. **设定卡片**

    - 人物设定：姓名（`name`）、简介（`profile`）、人物关系（`relationship: [{ type, target }]`，`type` 可用中文）等，人物与关系同属设定数据，支持增删改查并同步至记忆库

    - 物品设定：道具、功法、宝物、场景地点等设定分类管理，关联世界观与对应剧情节点

6. **编辑页（核心创作区）**

    - 右侧为 **AI Agent 对话栏**：右上角提供历史会话、新建对话、临时规则遮罩层

    - 正在 AI 续写：展示生成进度，支持随时中断、重新生成

    - AI 续写完毕：展示生成结果，提供全文采纳、部分采纳、丢弃重写操作选项

    - 修改续写内容：富文本编辑能力，支持手动修改正文，修改内容自动同步更新对应记忆

    - 前 3 章内容：侧边栏快捷查看最近 3 章正文，辅助上下文校验

    - 多次编写触发记忆进化：创作达到指定节点时，自动触发记忆更新，弹窗提示用户确认新增的设定信息

7. **记忆管理**

    - 写作风格：保存用户偏好的文风、句式、叙事习惯，支持多套风格模板切换与复用

    - 小说设定：集中管理全项目的世界观、人物、物品、大纲设定，支持关键词检索、批量编辑

    - 进化日志：完整记录所有记忆更新、设定修正、规则变更的历史，支持回溯与版本还原

8. **写作小助手**

    - 欢迎通知：新用户欢迎引导、基础功能使用提示

    - 记忆进化通知：主动推送记忆更新、设定补全、潜在设定冲突提醒

9. **帮助反馈**：使用教程、常见问题解答、功能意见反馈入口、问题客服通道

### 四、计划书输出要求

请按照以下结构输出完整计划书，内容详实、逻辑自洽：

1. 项目概述：包含产品定位、目标用户画像、核心价值、市场切入点

2. 产品整体架构：梳理功能全景框架，明确区分 Agent 底层能力层与前端应用层

3. 核心功能详细说明：针对上述所有功能模块展开细节描述与设计思路

4. 核心用户流程：梳理「新手创建项目全流程」「日常创作续写流程」「记忆管理与修正流程」三大核心路径

5. 技术实现方案：包含 Agent 架构设计、大模型接入方案、记忆库存储与检索方案、规则引擎设计思路

6. 版本迭代规划：划分 MVP 最小可行版本、V1\.0 正式版、后续进阶版本的功能边界与上线优先级

7. 风险与注意事项：包含内容合规、设定一致性、模型成本控制等风险点与应对思路
