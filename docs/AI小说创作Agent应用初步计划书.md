# AI 小说创作 Agent 应用产品初步计划书（本地个人版）

> 适用场景：个人独立开发、本地运行、数据本地存储、MVP 阶段仅提供本地启动的 Web 页面。  
> 注：部分内容基于需求整理与 AI 辅助生成。

---

## 1. 项目概述

### 1.1 产品定位

一款面向个人小说创作者的本地 AI 写作辅助工具。基于 Agent 思路实现，覆盖从世界观搭建到正文续写的核心流程。核心特点是：长期创作记忆、可自定义创作规则、灵活接入外部大模型 API，帮助作者在长篇小说创作过程中保持设定一致、风格统一。

### 1.2 目标用户

- 网文作者、原创小说作者、写作爱好者。
- 有自备大模型 API 密钥、愿意在本地管理创作数据的个人用户。

### 1.3 核心价值

1. **设定不崩**：通过本地记忆库跨章节维护人物、物品、世界观等设定。
2. **规则约束**：全局规则 + 单章节临时规则，约束 AI 生成方向。
3. **模型自由**：用户自己配置 API 密钥，按需选择模型。
4. **本地优先**：所有数据保存在本地，无需账号、无需云端。

### 1.4 边界说明

- **不部署云端**：无服务器、无数据库服务、无用户账号体系。
- **MVP 形态**：本地启动的 Web 页面，浏览器访问即可使用。
- **数据存储**：项目文件以本地 JSON / SQLite 形式保存，用户可自行备份或迁移。
- **后续可选**：如果体验成熟，再考虑是否打包为桌面 EXE，当前不做强制规划。

## 2. 产品整体架构

### 2.1 简化架构

```
┌──────────────────────────────────────────────┐
│           前端 Web 页面（浏览器访问）          │
│  项目列表 / 新手引导 / 设定管理 / 编辑页      │
├──────────────────────────────────────────────┤
│           本地后端服务（本地启动）             │
│  模型调用适配 │ 规则注入 │ 上下文组装         │
│  记忆读写 │ 技能提示词模板 │ 文件持久化       │
├──────────────────────────────────────────────┤
│           本地存储                             │
│  项目 JSON / SQLite │ 记忆库 │ 配置文件       │
├──────────────────────────────────────────────┤
│           外部依赖                             │
│  用户自备大模型 API（OpenAI/Claude/DeepSeek 等）│
└──────────────────────────────────────────────┘
```

### 2.2 模块关系

- **前端 Web 页面**：用户操作界面，所有功能在一个页面内或通过路由切换完成。
- **本地后端服务**：提供 API 接口给前端调用，负责模型请求、记忆管理、规则处理、文件读写。
- **本地存储**：项目、章节、设定、记忆、模型配置全部落盘到本地目录。
- **外部依赖**：仅大模型 API，由用户自行申请和配置密钥。

## 3. 核心功能详细说明

### 3.1 模型接入

- 用户在本地配置 API 密钥、选择模型、调整生成参数（temperature、top_p、最大 token 等）。
- 支持常见 OpenAI 兼容接口的模型：GPT、Claude、DeepSeek、通义千问、文心一言等。
- 配置保存在本地，不会上传到任何服务器。
- MVP 阶段先支持单一模型配置，后续可扩展为按任务选择模型。

### 3.2 自定义创作规则

- **全局规则**：作用于整个项目的文风、叙事视角、禁忌内容、世界观底层逻辑等。
- **单章规则**：针对当前章节临时追加规则，完成后可保留或丢弃。
- 规则以文本形式注入系统提示词，Agent 生成时统一遵循。
- MVP 阶段规则以简单文本列表管理，不做复杂的优先级冲突引擎。

### 3.3 分层记忆系统

- **长期记忆**：项目的世界观、人物、物品、剧情要点等结构化设定数据；人物关系内嵌于人物条目（`relationship: [{ type, target }]`，类型允许中文），不单独分类。
- **短期上下文**：自动携带最近 3 章正文 + 当前章节的已有内容，用于续写。
- **记忆更新**：新增内容达到指定字数或章节节点时，提示用户确认是否提取新设定；用户也可手动新增/编辑记忆。
- **存储方式**：长期记忆与项目绑定，保存在本地 JSON 文件中。

### 3.4 创作技能

- MVP 阶段内置少量高频技能：
  - AI 续写下一段
  - 润色当前段落
  - 扩写大纲/场景
  - 根据提示生成设定
- 技能通过预定义提示词模板实现，后续可开放用户自定义提示词。

### 3.5 产品端页面

#### 3.5.1 首页 / 项目列表

- 展示本地已有创作项目。
- 提供"新建项目"入口。
- 右上角「设置」进入**全局设置**（通用 / API / skill）。
- 无登录、无账号相关元素。

#### 3.5.2 新手引导（单页创建项目）

由原先五步五页浓缩为 **一页四区块**，创建后直接进入编辑器：

| 区块 | 内容 |
| --- | --- |
| 题材 & 世界观 | 作品名、题材分类、世界观简述 |
| 故事内核 | 核心主题、冲突、主线 |
| 主要角色 | 角色卡片（姓名、定位、简介；关系在展开编辑中维护） |
| 全本大纲 | 全书概要 + 分卷/单元梗概 |

- **AI 一键生成全部**：题材、内核、人物、大纲可由 AI 协同一次生成；也可先手填部分，再基于已有内容补全空白项。
- **分区块 AI 生成**：各卡片右上角可单独触发 AI 生成。
- **模态窗详细编辑**：世界观长文、角色卡、大纲等可点击展开，在模态窗中编辑后回写。
- 允许跳过或手动填写；确认后创建项目并初始化设定/记忆库。

#### 3.5.3 设定管理

- **人物设定卡**：`name`、`profile`、`relationship: [{ type, target }]`（`type` 为关系类型，可用中文；`target` 为对方角色名）等，人物与关系同属设定数据。
- **物品/地点设定**：道具、功法、场景地点等。
- **世界观设定**：势力、规则、历史背景等。
- 所有设定可增删改查，变更后自动用于后续 AI 生成。

#### 3.5.4 编辑页（核心创作区）

- 左侧：章节列表 + 最近 3 章正文快捷查看。
- 中间：当前章节编辑器，支持手动修改正文。
- 右侧：**AI Agent 对话栏**（非多 Tab 面板）：
  - 右上角：**历史会话**、**新建对话**、**临时规则**（遮罩层覆盖对话区，可返回继续对话）。
  - 对话区内展示生成结果与操作（插入文末、重写等）；底栏提供续写 / 润色 / 扩写 / 生成等快捷指令，并支持 `/skill` 调用。
- AI 续写：
  - 点击续写或对话触发，展示生成进度，支持中断。
  - 生成结果可全文采纳、部分采纳、丢弃重写。
- 达到记忆进化节点时弹窗提示，用户确认后更新记忆库。

#### 3.5.5 全局设置

入口：首页右上角「设置」。侧栏三栏：

| 栏 | 内容 |
| --- | --- |
| 通用 | 数据目录、自动保存、字数统计、删除确认等本地偏好 |
| API | 原「模型配置」：API 地址、密钥、默认模型、生成参数；测试连接；写入本地 `config.json` |
| skill | 原「技能库管理」：内置 / 自定义 SKILL.md 列表与编辑（frontmatter + 正文模板） |

模型与技能配置不再作为首页或编辑页的独立一级页面入口。

## 4. 核心用户流程

### 4.1 首次使用流程

```
本地启动服务 → 浏览器打开页面
    ↓
首页「设置」→ API 配置模型（只需一次，本地保存）
    ↓
新建项目 → 进入单页引导（可一键 AI 生成设定）
    ↓
确认创建项目 → 初始化设定/记忆库
    ↓
进入编辑页开始创作
```

### 4.2 日常创作流程

```
打开本地页面 → 选择项目
    ↓
进入编辑页，选择章节
    ↓
在右侧 Agent 对话栏发起续写/技能，或使用底栏快捷指令
    ↓
Agent 组装上下文（规则 + 长期记忆 + 最近 3 章 + 当前内容）
    ↓
调用配置模型生成正文
    ↓
用户审阅并采纳/修改/丢弃
    ↓
保存章节，触发记忆同步
    ↓
达到进化节点时，提示用户确认新增设定
```

### 4.3 记忆修正流程

```
进入设定管理
    ↓
查看人物（含内嵌关系）/ 物品 / 世界观 / 剧情要点
    ↓
发现冲突或遗漏
    ↓
手动编辑或新增设定条目（人物关系在角色卡上维护）
    ↓
保存，后续生成自动引用最新设定
```

## 5. 技术实现方案

### 5.1 技术选型建议

| 层级 | 建议方案 | 说明 |
| --- | --- | --- |
| 前端 | React / Vue + 富文本编辑器 | 单页应用，本地访问 |
| 后端 | Python FastAPI / Node Express | 本地启动，提供 API |
| 数据存储 | SQLite 或本地 JSON 文件 | 无需额外数据库服务 |
| 模型调用 | OpenAI 兼容接口封装 | 适配多种模型提供商 |
| 部署 | 本地命令启动（如 `npm run dev` 或 `python main.py`） | MVP 不做打包 |

### 5.2 后端核心模块

- **Model Client**：统一封装大模型调用，支持自定义 base_url、key、model、参数。
- **Prompt Builder**：根据任务类型组装系统提示词，注入规则、记忆、上下文。
- **Memory Store**：本地读写项目设定、章节、记忆数据。
- **Skill Handler**：根据技能类型选择对应提示词模板并调用模型。
- **File Manager**：管理项目目录、备份、导出。

### 5.3 存储结构（示例）

```
~/AINovelData/
├── config.json              # 模型配置
└── projects/
    └── project_001/
        ├── meta.json        # 项目基本信息
        ├── settings.json    # 全局规则、文风
        ├── memory.json      # 人物、物品、世界观等长期记忆
        ├── outline.json     # 大纲与章节列表
        └── chapters/
            ├── chapter_01.md
            └── chapter_02.md
```

### 5.4 记忆实现思路

- 长期记忆以结构化 JSON 存储，按世界观、人物、物品、剧情分类；人物含 `profile` 与 `relationship` 数组（`[{ type, target }]`）。
- 续写时从 memory.json 中抽取相关条目拼接进提示词（人物关系随 `$characters` 注入）。
- 记忆进化采用"字数/章节数触发 + 用户确认"机制，避免自动写入错误信息。
- 不做向量检索，先用关键词匹配 + 全量注入（项目初期设定量可控）。

### 5.5 规则注入思路

- 全局规则固定拼入每次系统提示词。
- 临时/单章规则由编辑页 Agent 栏「临时规则」遮罩层编辑，请求时附加。
- 规则就是一段自然语言约束文本，由模型自行遵循，MVP 阶段不引入复杂规则引擎。

## 6. 版本迭代规划

### 6.1 MVP 最小可用版本

**目标**：一个人能在本地跑起来，完成一次完整的小说创建与续写体验。

- 本地启动 Web 页面，浏览器访问。
- 本地模型配置（API 地址、密钥、模型、参数）。
- 新建项目 + 单页引导（AI 一键生成全部设定，可跳过）。
- 基础设定管理：人物（含关系）、物品、世界观。
- 编辑页：右侧 Agent 对话栏 + AI 续写、全文采纳/丢弃、手动修改正文。
- 最近 3 章上下文自动注入。
- 全局规则 + Agent 栏临时规则遮罩。
- 项目数据本地 JSON 落盘。

### 6.2 V1.0 完整可用版本

**目标**：把核心创作闭环跑顺，记忆与规则真正可用。

- 单页引导体验打磨（分区块生成、模态编辑、草稿回写）。
- 章节大纲管理，支持增删改排序。
- 记忆进化节点提示与人工确认。
- Agent 多会话历史与临时规则持久化（按章可选）。
- 内置技能：润色、扩写、生成设定。
- 设定关键词检索。
- 项目导出/备份。
- 错误处理与模型调用日志。

### 6.3 后续可选方向

**仅作为可能性列出，当前不投入开发。**

- 打包为桌面 EXE（如 Electron / Tauri）。
- 按任务配置不同模型。
- 用户自定义技能提示词。
- 简单的设定冲突检测。

## 7. 风险与注意事项

### 7.1 内容合规

- **风险**：AI 可能生成违规、低俗或侵权内容。
- **应对**：提供"禁忌内容"规则输入框，由用户自行约束；敏感内容责任由用户与所用模型服务商承担。

### 7.2 设定一致性

- **风险**：长文本中人物或设定前后不一致。
- **应对**：强制注入长期记忆；在记忆库中维护核心设定；鼓励用户定期修正记忆。

### 7.3 模型成本

- **风险**：长上下文调用消耗较多 Token。
- **应对**：上下文按 Token 限制自动裁剪；优先注入高度相关记忆；用户自行控制调用频率。

### 7.4 数据安全

- **风险**：API 密钥与创作内容均存在本地。
- **应对**：密钥仅保存在本地配置文件；建议用户自行备份项目目录；不连接任何远程服务。

### 7.5 模型效果波动

- **风险**：不同模型输出质量差异大。
- **应对**：支持丢弃重写；提供参数调节；提示词模板可迭代优化。

## 8. 结语

本计划书面向个人本地开发场景重新梳理，去掉了云端、账号、商业化等不必要的内容，聚焦"本地可运行、核心创作闭环可用"这一目标。建议 MVP 优先实现：模型配置、项目创建引导、设定管理、编辑续写、本地存储五条主线，先用最小成本验证产品价值。
